# Dunree rebrand - legacy-compat allowlist.
#
# Every line names a string that still spells the old product name ON PURPOSE, because something outside
# this source tree depends on it: an existing install's cookies or browser storage, a third-party plugin
# built with the Zoraxy SDK, a cluster peer on an older build, a monitor, a dashboard, a signed file.
# tools/rebrand/rename.py never rewrites a span matched here, in any file.  The work packages named in the
# last column add the Dunree name next to it and keep the old one working (docs/rebrand/plan.md has the
# row).  Delete a line only when the work package has replaced it with real compat code AND a test.
#
# Format:  id <2+ spaces or tab> python regex <2+ spaces or tab> plan row / work package: why
# (a regex therefore cannot contain two spaces in a row; use \s or [ ]{2})
