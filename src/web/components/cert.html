TLS / SSL Certificates

The certificates Zoraxy serves over HTTPS: when each one expires, which names it covers and whether it renews by itself.

Add a certificate

Choose how to get it. Each way asks only for what it needs.

How do you want to add the certificate?

The name visitors type. For one certificate that covers several names, separate them with commas.

The authority sends expiry notices here. Asked once and saved as the ACME email.

Before you request
  • The name already points at this server in public DNS.
  • Port 80 is reachable from the internet. Zoraxy opens it for the check if it is closed.
  • It takes about a minute. Keep this page open until you see the result.
How do you have it?

The public part. With intermediates: your certificate first, then the chain.

Stays on this server. It must not be protected by a password.

Server names and SNI. SNI is the host name a browser sends before the encrypted connection starts; Zoraxy uses it to pick the certificate.
  • For a.example.com and b.example.com a separate certificate for each answers fastest.
  • A wildcard certificate for *.example.com is added by entering example.com as the server name.
  • A certificate with several hosts: enter the first domain and Zoraxy matches the remaining CN/DNS names.

Filled in from the certificate when it can be read. For a wildcard certificate (*.example.com) enter example.com.

What you need
  • The certificate in PEM format: text that starts with -----BEGIN CERTIFICATE-----.
  • The private key that belongs to it, also in PEM format.
  • A separate intermediate certificate? Open the conversion tool to join them first.

The host name (or IP address) the certificate is for.

Other names or addresses the same certificate should cover, separated by commas.

Good to know
  • Browsers show a warning until the certificate is trusted on each device.
  • Valid for one year. It is not renewed automatically: create a new one before it expires.
  • The key is created on this server and never leaves it.
