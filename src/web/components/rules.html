      Help

      What can I type in "Domain to match"?
      Domain
      aroz.org sends every request for aroz.org to the target address.
      Subdomain
      s1.aroz.org sends requests for s1.aroz.org to the target address.
      Wildcard
      *.aroz.org sends every host name that matches to the target, such as www.aroz.org or foo.bar.aroz.org.
      What does "needs a TLS connection" mean?

      It describes the upstream server you proxy to: it only accepts secure (HTTPS) connections. It does not change whether visitors use HTTP or HTTPS to reach Zoraxy.

      Example: domain mydomain.com with target example.com:443 (TLS on). Visitors open mydomain.com, and Zoraxy talks to example.com:443 over HTTPS.

      If the upstream uses a self-signed certificate, also tick "Ignore TLS/SSL certificate errors" in the advanced settings.

      What is a sticky session?

      A sticky session keeps requests from the same visitor on the same upstream server. It helps applications that keep session data on one backend.

      It only works with more than one upstream. To add more:

      • Open HTTP Proxy in the menu.
      • Click Edit on the site.
      • Add upstreams in the Upstreams section.
