Use http://127.0.0.1:8081 in a proxy rule to reach the web server
How to reach the static web server

There are three ways:

  1. If Zoraxy is your gateway, add a proxy rule for a subdomain that points to http://127.0.0.1:8081
  2. If Zoraxy runs behind another reverse proxy, add http://127.0.0.1:8081 to that proxy's configuration
  3. Open it directly at http://{zoraxy_host_ip}:8081 (not recommended)

WebDAV server

Stopped · port :5488

Manage the files of the web folder with a WebDAV client. Changes are saved automatically.

For security, the WebDAV server only listens on localhost (127.0.0.1)
Advanced options

Credentials are saved separately from the other settings.

How to reach the WebDAV server

Step 1: add a proxy rule

Add a proxy rule for a subdomain (for example webdav.example.com) that points to http://127.0.0.1:5488

Step 2: connect with a WebDAV client

  • Windows Use WinSCP or map a network drive:
    1. Open File Explorer
    2. Right-click "This PC" and choose "Map network drive"
    3. Enter \\webdav.example.com@SSL\ (or http://webdav.example.com)
    4. Sign in with your Zoraxy admin user name and password
  • macOS Use Finder, Go, Connect to Server:
    1. Press Cmd+K
    2. Enter https://webdav.example.com
    3. Click "Connect" and enter your Zoraxy admin credentials
  • Linux Use the "Connect to Server" feature of your file manager, or mount it with davfs2:
    mount -t davfs https://webdav.example.com /mnt/webdav

Good to know

  • Use HTTPS (SSL/TLS) for secure connections
  • Sign in with your Zoraxy admin user name and password
  • The WebDAV server serves the whole www/ folder, including html/ (static web files) and templates/ (Zoraxy templates)
