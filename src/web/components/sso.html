Quick setup

Zoraxy asks an authorization server whether each request may pass: a 200-299 answer lets it through, any other answer is shown to the visitor. Works with Authelia, Authentik and OAuth2 Proxy. Enter the base URL of your server and click a preset: it only fills in the form, nothing is saved until you press Save changes.

For Authentik this is the URL of the proxy outpost. No path, no trailing slash.

Gateway

Zoraxy Auth is a built-in login system: you manage the users directly in Zoraxy.

Setup instructions

To use Zoraxy Auth, you will need to configure the gateway settings below.

  1. Enable the Zoraxy Auth gateway by toggling the switch below.
  2. Set up an HTTP proxy rule to forward the SSO domain to the Zoraxy Auth SSO port.
    e.g. auth.example.com → localhost:5489
  3. Configure the SSO Redirect URL in the settings below to point to the SSO domain.
    e.g. https://auth.example.com

Logout instructions

If your site uses Zoraxy Auth for SSO, for better UX, add a hyperlink to the logout URL in your application's navigation or user menu.

  1. To logout from SSO, navigate to the SSO domain and append /logout to the URL.
    e.g. https://auth.example.com/logout
  2. Click the "Log out from all services" button to end your session across all connected services.
