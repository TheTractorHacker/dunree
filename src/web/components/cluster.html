Cluster / HA

Run two or more Dunree nodes behind a load balancer: they share one secret, and a primary can copy its configuration to followers.

The shared secret makes visitor sessions (CAPTCHA, load balancer stickiness) valid on every node. Followers pull a signed, encrypted snapshot of the primary's proxy configuration. Standalone nodes (the default) are unaffected. Fleet, the other tab, adds per-node credentials, groups and staged rollouts; a node uses one of the two modes.

Cluster secret

Every node of a cluster needs the same secret of at least 32 characters. It is stored on this server and never shown again after it was generated. Changing it needs a restart of every node before session cookies use it.

Health endpoint

A status address for load balancers and keepalived scripts. On by default, open to everyone. It is served on the proxy listeners before host routing and answers 200 with the status, version, uptime and number of active endpoints, or 503 if the proxy is not running. It exposes no secrets. Use -health_port for a separate listener.
