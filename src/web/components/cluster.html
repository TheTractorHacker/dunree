Cluster / HA

Run two or more Dunree nodes behind a floating IP or a load balancer: they share one secret, and a primary can copy its configuration to followers.

The shared secret makes visitor sessions (CAPTCHA, load balancer stickiness) valid on every node. Followers pull a signed, encrypted snapshot of the primary's proxy configuration. Standalone nodes (the default) are unaffected. Fleet has its own page in the menu: it adds per-node credentials, groups and staged rollouts. A node uses one of the two, never both.

Other changes made here are overwritten by the next primary change (primary wins). Start with -cluster_allow_local_edits to lift the restriction. The primary also syncs its settings: the SSO providers and the SSO portal users are read-only here as well, and users change their password, 2FA and passkeys on the primary.
Floating IP
Each server keeps its own address. A small program on each server (keepalived) puts one more address, the floating IP, on the server that is healthy, and moves it when that server or Dunree on it stops answering. Dunree writes one script per server and shows the progress here. It never changes your servers or your router itself: you run the scripts. Guide: docs/guides/floating-ip-keepalived.md.

Your two servers share one extra address. Your router sends visitors to that address, and whichever server is healthy answers on it.

    Pick the floating IP

    One spare address in your network that no device uses. Visitors reach your proxy on it, whichever server is up.

    Suggestions

    Likely free, not proven. Dunree only asked the network; a device that is switched off right now would not answer.

    Your router gives out addresses automatically from a range. Pick one outside it. In UniFi: Settings > Networks > your network > DHCP range.

    If the router gives the floating IP to another device, two devices answer on it and your site breaks. Don't make a fixed-IP reservation for the floating IP either: it moves between two servers.

    Tick this box once you have checked it in your router.

        Health endpoint

        A status address for load balancers and keepalived scripts. On by default, open to everyone. It is served on the proxy listeners before host routing and answers 200 with the status, version, uptime and number of active endpoints, or 503 if the proxy is not running. It exposes no secrets.
