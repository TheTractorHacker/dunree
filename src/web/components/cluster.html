Fleet Cluster / HA
Shared-secret mode Nodes that share a secret accept each other's visitor sessions, and a primary can copy its configuration to followers. For central management use Fleet; a node uses one of the two modes. The shared secret makes visitor sessions (CAPTCHA, load balancer stickiness) valid on every node. Followers pull a signed, encrypted snapshot of the primary's proxy configuration. Standalone nodes (the default) are unaffected. Fleet adds per-node credentials, groups and staged rollouts.

Health endpoint

A status address for load balancers and keepalived scripts. It is served on the proxy listeners before host routing and answers 200 with the status, version, uptime and number of active endpoints, or 503 if the proxy is not running. It exposes no secrets. Use -health_port for a separate listener.
