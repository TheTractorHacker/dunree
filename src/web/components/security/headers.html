Header access rules

Require a request header, such as a secret set by your CDN, on a proxy rule. Requests without it are denied. Nothing happens until you add a rule.

A request must pass every rule of the proxy rule. A rule passes if any of its values matches, so you can rotate a secret by adding the new value first and removing the old one later. Secrets are never logged or shown again; leave a secret field empty to keep the stored one.
