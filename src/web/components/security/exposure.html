Destination restriction

Stops this Zoraxy from being used to reach places it should not. Off until you configure it; nothing changes for an existing setup.

One per line: a network or address, optionally followed by ports (443 or 8000-8100), or written as 10.0.0.5:443. While the list is not empty, a proxy rule, upstream, path route or default site outside it is refused when saved, even with the switch off. Empty means no restriction. Local addresses are only reachable when listed; metadata and link-local addresses never are.

Admin panel allow-list

Only these networks may connect to the admin port (); everyone else gets "403 Forbidden". Empty means no limit.

One IP address or range (CIDR) per line. Your address, , must be in the list, so you cannot lock yourself out from here. 0.0.0.0/0 is refused.

The API, plugin and Fleet or cluster endpoints on the admin port are covered too, so list the hosts that use them. Requests that a proxy rule forwards to the admin port are refused while a list is set. If you are locked out anyway, stop Zoraxy and start it once with -reset_admin_allowlist.

This page does not change your firewall. Keep your firewall rules; these limits are a second layer.
