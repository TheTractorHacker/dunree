Who may open the admin panel

Everyone

Only the networks you list may connect to the admin port (); everyone else gets "403 Forbidden". An empty list means no limit.

One IP address or range (CIDR) per line. Your address, , must be in the list, so you cannot lock yourself out from here. 0.0.0.0/0 is refused.

What else is covered, and how to get back in

The API, plugin and Fleet or cluster endpoints on the admin port are covered too, so list the hosts that use them. Requests that a proxy rule forwards to the admin port are refused while a list is set.

If you are locked out anyway, stop Zoraxy and start it once with -reset_admin_allowlist.

Where Zoraxy may connect to

Anywhere

Stops this Zoraxy from being used to reach places it should not, such as other machines in your network. Nothing changes for an existing setup until you configure it.

One per line: a network or address, optionally followed by ports (443 or 8000-8100), or written as 10.0.0.5:443. Empty means no restriction.

What exactly is refused

While the list is not empty, a proxy rule, upstream, path route or default site outside it is refused when saved, even with the switch off.

Local addresses are only reachable when listed; metadata and link-local addresses never are. Uptime checks of an upstream on 127.0.0.1 fail while the switch is on unless you list it.
