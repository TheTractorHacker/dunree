Credential lists

Named lists of users that several proxy rules can share, on top of each rule's own users. Passwords are stored hashed and never shown.

Add or change a list

One per line as username:password. Leave the password out to keep an existing user's password.

Per proxy rule

Choose which lists protect a proxy rule and, if you like, only some paths. Basic auth must also be the rule's authentication method (HTTP Proxy, Authentication).

Separate list names with commas.

Separate with commas. Empty protects the whole host.
