Shared login lists

A list is a set of user names and passwords that several sites can share for the browser's own login prompt. Passwords are stored hashed and never shown.

New list

One user per line as username:password. Passwords are stored hashed and never shown again.

Saving under the name of an existing list changes that list.

Leave the password out to keep an existing user's password.
