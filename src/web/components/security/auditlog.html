Security audit log

Who changed a security setting, from which address, and what. It records the deployment role, trusted proxies, access lists, the admin allow-list, upstream certificate trust, API tokens, WAF, auto-ban and rate limit settings, and configuration import, export and restore. Passwords, tokens, cookies and private keys are never written; other secret-looking values show as [redacted]. Sign-ins and admin accounts are in the Admin accounts section. The file is conf/security_audit.log, kept as 5 files of 5 MiB, not included in configuration exports, and the addresses shown are the direct connection, not forwarded headers.
