CrowdSec

Use a CrowdSec Local API (LAPI) that you run as a block list for this proxy. Zoraxy keeps the ban decisions in memory (stream mode) and checks every visitor address against them. Off until you switch it on, and it starts in Log only mode: matches are counted and logged, nobody is blocked. With two Zoraxy instances, point both at the same LAPI. Detection (feeding CrowdSec your logs) and reporting alerts back to CrowdSec are not part of this; see the CrowdSec guide.

Cloud metadata and link-local addresses are always refused; loopback and private addresses are fine. Use https when the LAPI is not on this machine.

Create it with cscli bouncers add zoraxy. It is stored encrypted, never shown again and left out of exports. Leave empty to keep the stored key.

Default is fail open: if the LAPI cannot be reached for longer than the time above, traffic is allowed and only the decisions already in memory apply. Fail closed only has an effect in Enforce mode, and a LAPI outage then takes your sites offline.
