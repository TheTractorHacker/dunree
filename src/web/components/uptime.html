What counts as up

Choose which answers from a site are treated as online.

Leave empty to accept any answer except gateway errors (502, 503, 504, 52x). Example: 200-399.

Comma separated: single codes (401), ranges (200-399), classes (2xx) or any. Empty means any, so login-protected apps are not shown offline. Use 200-399 to require a success or redirect. A single proxy rule can override this in its editor.
