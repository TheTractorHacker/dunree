Signed plugin index

A signed index lists the exact download, checksum and size of every plugin and is signed with a plugin key. The index that ships with Dunree is not signed, so its plugins show as "Unsigned". Whatever you choose, a plugin is only updated from the index it was installed from.

The public half of the key the index is signed with (PEM, or 32 bytes in base64 or hex). It is not a secret. Never paste a private key here.
