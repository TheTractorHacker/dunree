Create a token

Give it a name you will recognise and the least access it needs. Read only is the default.

What uses it. Shown in the list above.

Read only can look (GET requests). Read / write can also change the configuration.

Leave empty for a token that never expires.

Empty means any address. Separate several with commas. The address comes from the TCP connection, so behind a reverse proxy list the proxy's address.

The token is shown once, at the top of this page.

Use a token

Send it in the Authorization header of every request to /api/v1.

curl -H "Authorization: Bearer YOUR_TOKEN" /api/v1/
  • Tokens work for /api/v1 only. They cannot sign in to this interface.
  • A read-only token is refused for anything but GET requests.
  • Changes made with a token are recorded in History under the token's name.
