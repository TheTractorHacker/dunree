Current state

Zoraxy runs the external zrok program for you. Set it up in the three steps below.

About this feature
The command lines follow the zrok 1.1 and 2.0 sources and were tested with a stand-in zrok program, not against a live zrok service. Please report differences you find with your zrok version. Tunnel programs run with their own home folder, are restarted automatically after a failure and are stopped when Zoraxy shuts down.

1 Install zrok

Zoraxy needs the zrok program on this machine.

zrok is not installed on this machine
  1. Download the release for this machine from github.com/openziti/zrok/releases (binary zrok for 1.x, zrok2 for 2.x).
  2. Put it on the PATH of the user running Zoraxy (for example /usr/local/bin), or enter its full path below. The file name must start with zrok.
  3. Press Check again. In a container the binary must exist inside the container.
Technical details
Binary location, command line version and self-hosted endpoint

2 Enable the environment

Paste the account token of your free account at zrok.io (or of your own zrok service).

Stored on this machine and never shown again.
The token is saved in conf/zrok/token (file mode 0600) and removed from logs. zrok only accepts it as a command line argument of zrok enable, so it is visible in the process list for the few seconds that command runs. Zoraxy does not learn your account name from zrok: it only knows whether a token is stored and whether zrok enable succeeded.
