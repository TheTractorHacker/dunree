Fleet

Manage several Dunree nodes from one hub: one place for their configuration, health and rollouts.

The hub publishes versioned configuration for the scopes you choose. Nodes pull it with their own credentials and keep everything else local. The hub can only publish configuration and ask a node to sync: it can never run commands on a node.
Fleet

This node is part of Cluster / HA. Switch it to standalone there before you start or join a Fleet. Open Cluster / HA

Run this node as the hub

This Dunree becomes the management console for your other nodes.

  • Publishes versioned configuration for the scopes you choose.
  • Shows the health, version and sync state of every node.
  • Rolls out changes to one node first (canary) or to all at once.
  • Can never run commands on a node.

Its own configuration is what gets published to the nodes. Use node variables in proxy rules only if the hub does not proxy those sites itself.

Not available while this node is in Cluster / HA. See the note above.

Move, re-key or remove

Each of these acts at once. Revoke and Remove ask first.

  • Move to another groupThe node then receives what that group manages.

  • Rotate the node keyThe node picks the new key up at its next sync.

  • RevokeIts credentials stop working immediately. The node stays in the list.

  • Remove from the hubThe node keeps its current configuration but is no longer managed. It finds out the next time it contacts the hub and then offers to leave the Fleet. A node that left on its own stays in this list as offline until you remove it here.
