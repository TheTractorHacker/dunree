Fleet

Manage several Zoraxy nodes from one hub.

The hub publishes versioned configuration for the scopes you choose. Nodes pull it with their own credentials and keep everything else local. The hub can only publish configuration and ask a node to sync: it can never run commands on a node.
Fleet Cluster / HA

Run this node as the hub

This Zoraxy becomes the management console for your other nodes.

  • Publishes versioned configuration to the scopes you choose.
  • Shows the health, version and sync state of every node.
  • Rolls out changes to one node first (canary) or to all at once.
  • Can never run commands on a node.

Its own configuration is what gets published to the nodes. Use node variables in proxy rules only if the hub does not proxy those sites itself.
