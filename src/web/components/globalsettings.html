Listening now

Every address Zoraxy accepts visitors on. The first three are set on this page; extra ports belong to single sites.

ListenerAddressServesState

      Extra ports are shown as configured: Zoraxy does not report whether each one could be opened. If a port does not answer, look in the system log for "address already in use".

      Add a listening port for one site

      Let one site also answer on a port of its own, for example :8443. It keeps answering on the main listener. Zoraxy tries to open the port at once.

      As :port for every network card, or ip:port for one. Not a port a listener on this page or the management interface already uses. The same list is in the editor of the site, under Networking.

      Main listener

      The port all your sites answer on. The port is applied with Save changes; the HTTPS switch applies at once.

      Normally 443 with HTTPS, 80 without. It cannot be the port of this management interface.

      Plain HTTP listener

      A second listener for http:// while the main one speaks HTTPS: to send visitors on to HTTPS, and for Let's Encrypt HTTP-01 validation. Off by default.

      Switches apply immediately
      The HTTP listener is on but not running Another program probably uses the port already. Stop it, or choose another address.

      As :port or ip:port; the default is :80. Use for example :8080 behind a port forward. Applied with Save changes, which restarts the proxy. Let's Encrypt still has to reach it on public port 80.

      TLS versions and ciphers

      Which TLS versions and cipher suites the HTTPS listener offers. The defaults suit almost every setup.

      Applies immediately
      Minimum TLS version

      Clients that only speak an older version are refused.

      Intermediate and Modern drop the old CBC ciphers that SSL scanners flag. Intermediate needs TLS 1.2, Modern needs TLS 1.3; the minimum version is raised for you.

      Protocols

      Both are off by default, and only one of them can be on: switching one on switches the other off.

      Applies immediately

      Timeouts

      How long Zoraxy waits for a slow client. In whole seconds; 0 means no limit. Saving restarts the proxy if it is running.

      Applied with Save changes
      sec

      Time to send the request headers. Stops slow-header (Slowloris) attacks. Default 30.

      sec

      Time to send the whole request with its body. Keep it above your slowest upload. Default 0.

      sec

      Time to send the whole response. Keep 0 for large downloads and streaming. Default 0.

      sec

      How long an unused keep-alive connection stays open. Default 300.

      Client IP headers

      Stop visitors from faking their address towards your upstream servers.

      Applies immediately

      Security headers for new sites

      A preset of hardened response headers that every site you create from now on starts with. Off by default. Existing sites are not changed, and each site can still change the headers or turn them off.
