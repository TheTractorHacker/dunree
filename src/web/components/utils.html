Configuration backup

A backup is one ZIP file with your proxy rules, certificates and settings. Keep it somewhere safe: it can contain private keys.

  • Download a backupChoose what goes in: everything, the configuration only, or a copy without secrets that is safe to share.
  • Restore from a backupCheck a backup file first (dry run), then restore it. Restoring replaces the current configuration and stops Zoraxy so it starts with the restored one.

Both open in a side panel. Nothing is downloaded or changed until you confirm there.

  • Saved versionsEvery change made in this interface is saved as a version you can compare and go back to, without a backup file.
    Open History
  • Backup before an updateThe updater can copy the configuration and the database before it installs a new version.

Log rotation

Without rotation the Zoraxy log keeps growing. With it, a full log is moved to a numbered backup file and a new one is started.

A number of bytes, or add K, M or G (200M). 0 turns the size limit off.

Older ones are deleted.
