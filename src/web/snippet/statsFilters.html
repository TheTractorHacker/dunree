Statistics Filters
Choose what is recorded in the statistics. Changes apply to new requests only.

Exclude IP addresses

Requests from these addresses or CIDR ranges are not counted (one per line), e.g. your own IP.

Query string in requested paths

Controls how "Top requested paths" records the query string. Query strings can contain secrets such as tokens.

Keep daily statistics for

Statistics keep one record per day and, by default, never delete old days, so the database grows with time. Choose how long to keep them; older days are deleted when you save, when Zoraxy starts and every midnight. The file only gets smaller after an offline compaction (zoraxy -compact-db). Off by default.
