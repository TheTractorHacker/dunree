Config Export and Import Tool
Painless migration with one click

Back up the current configuration

This will download all your configuration on zoraxy in a zip file. This includes all the proxy configs and certificates. Please keep it somewhere safe and after migration, delete this if possible.

A shareable archive always carries a manifest.json (versions, mode, size and SHA-256 of each file) so a restore can verify it. For the other modes it is optional, because a Zoraxy that predates the manifest cannot restore an archive that has one.

Restore from a backup

You can restore your previous settings and database from a zip file config backup.

Restoring a full system snapshot shuts Zoraxy down

Zoraxy exits when the restore completes. Make sure it is set up to restart automatically (for example with systemd) so it comes back with the restored configuration.

Check file validates the archive and shows what would be added, replaced and removed without changing anything.

The current config will be backup to ./conf_old{timestamp}. If you screw something up, you can always restore it by ssh to your host and restore the configs from the old folder.
Nothing is half restored: if a step fails the previous config is put back. Restoring a shareable archive keeps the secrets this installation already has.
